# dotfiles-palenight
Dotfiles for my main i3 setup

## Basic Keybinds
'$mod + Shift+ b': Microsoft Edge
'$mod + Shift + s': Spotify
'$mod + Shift + o': Obsidian
'$mod + Shift + d': Visual Studio Code

## Display Keybinds
'$mod + Control+ Shift + 1': Dual Monitor
'$mod + Control+ Shift + 2': Focus Only For Second Monitor (HDMI)
